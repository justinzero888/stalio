# Stalio onboarding flow  
  
You're absolutely right. A 10-step onboarding is death for conversion. Let's compress everything into **3 screens** that respect the user's intelligence and get them to value immediately.  
  
---  
  
# Stalio 跬步 — 3-Screen Onboarding Flow  
  
## Core Principle  
  
> **"Show, don't tell. Trust the user to figure it out."**  
  
---

## Full 3-Screen Flow — Summary Table  
  
| Screen | Purpose | Content | User Action | Time |  
|--------|---------|---------|-------------|------|  
| **1. Welcome** | Brand + philosophy | Tally icon, tagline, value prop | Tap "Get Started" | 3-5s |  
| **2. How It Works** | Educate on 3 interaction types | Show examples: One Tap, One Number, One Note + help reminder | Tap "Select Your Habits" | 10-15s |  
| **3. Select Habits** | Choose default habits | 9 pre-selected habits with tracking type indicators, add more option | Toggle habits, tap "Start Tracking" | 15-20s |  
| **→ Dashboard** | Start tracking | All selected habits, progress bar, help available | Start tapping habits | — |  
  
**Total onboarding time: < 60 seconds**  
  
---  
  
## Key Design Decisions  
  
| Decision | Rationale |  
|----------|-----------|  
| **3 screens max** | Users abandon long onboarding. Get to value quickly. |  
| **Explain interaction types before selection** | User needs to know what they're signing up for before choosing habits |  
| **Pre-select all 9 habits** | Decision fatigue is real. Defaults reduce friction. |  
| **Tracking type icons on habits** | Visual cues help users understand what to expect |  
| **Help is contextual, not upfront** | Don't overwhelm with information users don't need yet |  
| **No time setting in onboarding** | Can be set later. Not a blocker to start tracking. |  
| **No notification permission upfront** | Ask in context when it matters (e.g., when user sets a reminder) |  
| **"Add more from library" is optional** | Power users can explore; casual users can ignore |

## Implementation Notes  
  
### Screen Transitions  
  
| Transition | Animation | Duration |  
|------------|-----------|----------|  
| Welcome → How It Works | Slide up | 300ms |  
| How It Works → Select Habits | Slide up | 300ms |  
| Select Habits → Dashboard | Fade + scale | 400ms |  
  
### Data Persistence  
  
```javascript  
// On "Start Tracking" click  
function completeOnboarding(selectedHabits) {  
  // 1. Save selected habits to user profile  
  saveUserHabits(selectedHabits);  
    
  // 2. Mark onboarding as complete  
  setOnboardingComplete(true);  
    
  // 3. Set default times (if not set by user)  
  setDefaultMorningTime('07:00');  
  setDefaultEveningTime('21:00');  
    
  // 4. Navigate to dashboard  
  navigateToDashboard();  
}  
```  
  
### Default Times  
  
Even though we don't ask for time settings in onboarding, we set sensible defaults:  
  
| Setting | Default |  
|---------|---------|  
| Morning check-in time | 7:00 AM |  
| Evening check-in time | 9:00 PM |  
| Notifications | Off (user can enable later) |
